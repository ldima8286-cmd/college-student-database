# 🎓 База данных учащихся колледжа

Дипломный проект — веб-приложение для учёта студентов колледжа с возможностью добавления, редактирования, удаления записей, управления академическими задолженностями, поиска и фильтрации.

**🔗 Публичная демо-версия:** [https://ldima8286.github.io/college-student-database](https://ldima8286-cmd.github.io/college-student-database/)

---

## 📋 Функциональные возможности

| Модуль | Описание |
|--------|----------|
| **CRUD студентов** | Добавление, просмотр, редактирование, удаление записей |
| **Управление задолженностями** | Добавление/снятие академической задолженности одним кликом |
| **Поиск и фильтрация** | Поиск по ФИО, группе или специальности в реальном времени |
| **Импорт/экспорт** | Выгрузка всех данных в JSON и загрузка из JSON |
| **Тёмная тема** | Переключение между светлой и тёмной темами интерфейса |
| **Адаптивный дизайн** | Корректное отображение на ПК, планшетах и смартфонах |

### 👥 Роли пользователей
- **Администратор** — полный доступ: CRUD студентов, управление пользователями, просмотр логов, удаление логов.
- **Преподаватель** — доступ только к своим группам: просмотр студентов, управление задолженностями, редактирование посещаемости и успеваемости.

### 📋 Основные модули
| Модуль | Описание |
|--------|----------|
| **Управление студентами** | Добавление, редактирование, удаление, просмотр списка с фильтрацией по ФИО/группе/специальности. |
| **Посещаемость и успеваемость** | Визуальная индикация (зелёный/жёлтый/красный), быстрое редактирование. |
| **Академические задолженности** | Добавление/снятие задолженности одним кликом. |
| **Импорт/экспорт JSON** | Полная выгрузка и загрузка данных. |
| **Журнал действий (логи)** | Автоматическое логирование всех действий пользователей (вход, CRUD, переключение долгов). Админ может очищать логи. |
| **Тёмная/светлая тема** | Переключение с сохранением в localStorage. |
| **Адаптивный дизайн** | Корректно работает на ПК, планшетах и телефонах. |

## 🚀 Запуск проекта (локально)

### Требования
- Node.js 16+
- npm 8+ или yarn

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/ldima8286/college-student-database.git
cd college-student-database

# Установка зависимостей бэкенда
cd backend
npm install

# Установка зависимостей фронтенда
cd ../frontend
npm install
