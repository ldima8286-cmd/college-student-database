# 🎓 База данных учащихся колледжа

Дипломный проект — веб-приложение для учёта студентов колледжа с возможностью добавления, редактирования, удаления записей, управления академическими задолженностями, поиска и фильтрации.

**🔗 Публичная демо-версия:**[ https://ldima8286.github.io/college-student-database](https://ldima8286-cmd.github.io/college-student-database/)

---

## 📋 Функциональные возможности

| Модуль | Описание |
|--------|----------|
| **CRUD студентов** | Добавление, просмотр, редактирование, удаление записей |
| **Управление задолженностями** | Добавление/снятие академической задолженности одним кликом |
| **Поиск и фильтрация** | Поиск по ФИО, группе, специальности, email или телефону с пагинацией |
| **Импорт/экспорт** | JSON и Excel; пакетное удаление и экспорт выбранных записей |
| **Авторизация** | Регистрация, вход по email/паролю, JWT с refresh-токенами, bcrypt-хеширование |
| **Профиль** | Смена пароля, аватар, контактные данные |
| **Аудит-лог** | Журнал действий администраторов с фильтрами |
| **Тёмная тема** | Переключение между светлой и тёмной темами интерфейса |
| **PWA** | Установка на устройство, офлайн-режим |
| **Интеграции** | Вебхуки, email-уведомления (SMTP) |
| **Адаптивный дизайн** | Корректное отображение на ПК, планшетах и смартфонах |

## 🚀 Запуск проекта (локально)

### Требования
- Node.js 16+
- npm 8+ или yarn

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/ldima8286/college-student-database.git
cd college-student-database

# Установка зависимостей бэкенда
cd backend
npm install

# Установка зависимостей фронтенда
cd ../frontend
npm install
```

### Миграции БД

Проект поддерживает SQLite (по умолчанию) и PostgreSQL. Схема создаётся автоматически при старте, но для управления миграциями:

```bash
cd backend
npm run db:generate              # сгенерировать миграции (PostgreSQL)
npm run db:migrate               # применить миграции (PostgreSQL)
npm run db:generate:sqlite       # сгенерировать миграции (SQLite)
npm run db:migrate:sqlite        # применить миграции (SQLite)
```
